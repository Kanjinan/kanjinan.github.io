Metal Slug Enhanced : le Metal Slug d'origine, réglé comme vous voulez.

Un ROM hack du premier Metal Slug (Nazca / SNK, 1996) sur Neo Geo. Le jeu reste le même : le hack ajoute un menu d'options, modifié directement dans le code 68000 d'origine. Avec les réglages par défaut, le jeu est identique à l'original.

L'écran START / OPTION

Au lancement d'une partie, un écran START / OPTION apparaît, en arcade (MVS) comme sur console (AES). Le mot ENHANCED s'affiche sous le logo, sur l'écran titre et dans le mode attraction.

Le menu OPTION

  • LEVEL : la difficulté (EASY, NORMAL, HARD, MVS).
  • MISSION : la mission de départ, de 1 à 6.
  • HERO : le nombre de vies, de 1 à 9, ou des vies infinies.
  • LANGUAGE : la langue du tutoriel : automatique, anglais, portugais, japonais, et l'espagnol, une langue cachée dans le jeu d'origine.
  • ARMS : l'arme de départ à chaque vie : pistolet, Heavy Machine Gun, Rocket Launcher, Flame Shot ou Shotgun.
  • KEEP ARMS : quand vous mourez, vous gardez votre arme et ses munitions.
  • AMMO : munitions infinies.
  • BOMBS : les grenades au départ (10, 20, 30, 50, 99) ou des grenades infinies.
  • TIME : le chrono (réglage du jeu, 60 à 90 secondes, ou infini).
  • EFFECTS : FULL ou LIGHT. LIGHT supprime quelques effets visuels purement décoratifs pour réduire les ralentissements. Dans la mission 5, la plus chargée, la part d'images ralenties passe de 25 % à 7 %.

Haut et Bas pour choisir la ligne, Gauche et Droite pour changer la valeur, A sur EXIT pour valider. Sur MVS (et dans MAME), les réglages sont sauvegardés. Sur AES, ils sont gardés jusqu'à l'extinction. En partie à deux, chaque joueur reçoit son arme et ses propres munitions.

Installation

Le hack est distribué sous forme de patchs IPS, intégrés dans un outil qui construit le jeu à partir de votre romset MAME mslug.zip (voir ci-dessous). Fonctionne sur MAME, MiSTer et NeoSD. L'outil produit aussi les fichiers pour Darksoft et BackBit Platinum MVS. Les patchs IPS sont aussi dans l'archive, pour les appliquer avec l'outil de votre choix.
